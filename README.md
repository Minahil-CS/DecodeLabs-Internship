# Project 1: Rule-Based AI Chatbot

A rule-based chatbot built in Python for the DecodeLabs AI Internship (Batch 2026).

## Features
- Continuous input loop (`while True`)
- Input sanitization (case, whitespace, punctuation)
- Dictionary-based knowledge base (12 intents, O(1) lookup)
- Fallback response for unknown inputs
- Clean exit command (`bye`, `exit`, `quit`)

## Run
python chatbot.py
